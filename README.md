# Neurocentrx PI clinician feedback forum

Live forum: https://jeffroix.github.io/nrcx-pi-response-forum-public/

This is a public, static, view-only copy of the clinician feedback forum. It is intended for review of clinical positions and trial-conduct questions from the PI briefing package.

## Use the forum

1. Open the live link.
2. For each topic, choose **Approve**, **Approve with changes**, or **Do not approve**.
3. Add any suggested clinical change, safeguard, wording, or practical trial-conduct point in **Details you would add**.

Choices and notes stay in the current browser. They are not submitted or stored. Send substantive comments back through the agreed Teams discussion.

The main areas are home treatment, caregiver involvement, telehealth, digital-health follow-up, safety monitoring, abuse-liability assessments, clinical management, discharge/escalation, and driving safety. Slides 18–19 are the priority decision slides; Slides 5 and 13 provide context.

## Suggest or make changes

The repository is public so the HTML can be inspected. If you have a GitHub account, you can fork the repository, make changes in your own branch, and open a pull request. Alternatively, send suggested wording or question changes in Teams for consolidation.

Do not add PHI, patient-level information, confidential source text, credentials, or a response database. Keep the public copy static and view-only.

The internal ChatGPT Sites copy remains the fallback review surface.
